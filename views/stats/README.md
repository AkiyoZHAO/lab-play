# 统计视图（stats）

> 状态：**骨架待实现**。这是账本的一个**视图**，不是 play——它不产生新数据，只汇总所有 play 写进 events 的痕迹。

## 定位

落实项目书里的「周期性回顾摘要」：把累积的事件转化为可感知的「这段时间其实做了这些」的证据，对抗「好像什么都没留下」的空虚感。终点是**证据**，不是奖励。

## 计划中的内容（下一轮实现）

- 时间范围筛选（最近 7/30 天 / 全部 / 自定义）
- KPI：总次数、完成率、完成/跳过数
- 趋势图、完成占比、活动完成率排行
- （可选）把筛选结果丢给 AI 生成一段文字总结

## 与 events 的关系

只读，通过 [`core/events.js`](../../core/events.js) 的 `queryEvents(filters)` 拉取事件，在前端聚合。**不新增任何表、不单独存状态**——所有数字都是对 events 表的实时计算。

## 视觉约束

遵守 [`design/DESIGN.md`](../../design/DESIGN.md)：中性 light 雅致，图表配色用设计 token 里的中性阶 + 克制的语义色（`--c-positive` / `--c-negative`），不堆高饱和色块。
